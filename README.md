# My 13 Ticket

Biglietto interattivo per il 13° anniversario — 8 settembre 2013 → 8 settembre 2026.

## Pubblicazione
Il sito usa `index.html` nella root e 10 immagini in `assets/` chiamate `memory-01.jpg` … `memory-10.jpg`.

Per GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

La pagina include il percorso interattivo, 10 ricordi, 13 frasi da sbloccare, la canzone `Burattino` dei Two Fingerz tramite YouTube e il reveal finale della gift card libri.
